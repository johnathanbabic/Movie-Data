# Movie Data Analysis

This was a personal learning project where I used a movie dataset to get more familiar with Python and data analysis.

I worked with the data to practice cleaning and organizing datasets, calculating averages, identifying trends and correlations, and creating visualizations. The main goal was to experiment with different techniques and gain hands-on experience working with real-world data.

## What I Practiced

- **Data Cleaning:** Formatting and preparing data for analysis.
- **Data Exploration:** Exploring movie data to identify patterns and relationships.
- **Statistical Analysis:** Calculating averages and examining correlations between variables.
- **Data Visualization:** Creating charts to better understand and present findings.

## Project Files

- `Movie data.ipynb` – Jupyter Notebook containing the Python code and analysis.
- `movies.csv` – Movie dataset used throughout the project.

## About

This project was created for learning and experimentation rather than as a finished application. It helped me build a better understanding of how Python can be used to explore, analyze, and visualize datasets.
